# NAS 挂载盘与网络共享

在「设置 → 简单」填写对应格式的保存目录，可以直接输入，也可以点击「选择」。Windows 支持映射盘，例如 `Y:\music\dolbyatmos`，以及 UNC 路径，例如 `\\NAS\music\dolbyatmos`。文件管理页可以浏览这些保存目录。

如果 NAS 使用 WebDAV、SFTP，可以先用系统或挂载工具将目录挂载为盘符，再填写该盘符下的目录。当前版本通过挂载后的文件系统读写。

直接编辑 YAML 时，Windows 路径建议使用单引号：

```yaml
atmos-save-folder: 'Y:\music\dolbyatmos'
alac-save-folder: '\\NAS\music\ALAC'
```

也可以使用正斜杠：

```yaml
atmos-save-folder: 'Y:/music/dolbyatmos'
```

表单会自动处理 YAML 转义。旧版本生成的双引号内未转义的 Windows 路径，在启动或保存配置时会修复。

启动桌面端前，先在资源管理器中确认盘符或共享可访问。应用需与挂载盘处于同一 Windows 登录会话；以管理员身份启动的进程可能看不到普通用户映射的盘，此时可以使用 UNC 路径。NAS 账号需要对保存目录有读写权限。

歌曲先在每首独立的本地临时目录完成下载、解密、封装、元数据写入和可选格式转换，再复制到保存目录中的唯一临时文件，关闭文件后重命名为最终文件名。这可以减少并发下载时直接改写网络文件的占用冲突；同名歌曲在不同专辑中的标签临时文件也各自独立。

遇到 Windows 短暂的共享/锁定冲突，标签写入和最终重命名会在最多约 10 秒内重试。若成品仍无法发布，日志会显示本地成品保留路径，可从该位置恢复；目标目录中的已有文件会保留。该流程使用本机临时磁盘空间，歌词和封面等独立文件仍保存在配置的目录。
